TLDR: v0.18.0 puts Ember, the interface, and the installer on one version number. Ember stopped inventing links, stopped misreading how old her own records are, and holds up better in long conversations. The interface passed an accessibility audit. The installer runs on Linux.

One Version Number

Three pieces, one number: Ember was at 0.17.1, the interface and installer at 0.8.1. All three are now 0.18.0 and move together from here. Nothing was skipped. The interface and installer numbers jumped to catch up.

Character and Behavior

No more invented links: Asked about something she had thin records for, Ember would sometimes produce a plausible-looking URL that led nowhere. Any link not backed by a real source is now stripped and shown as "[unverified link]".
Less coaching register: The filter catching "let's work through this" and endless follow-up questions got broader, and now checks intent before firing so it stops rewriting answers that were already fine.

Memory and Retrieval

Recent conversations are findable again: Ember was reading from an index that had not refreshed since April, so recent conversations could be invisible to search. That index is retired; everything reads from the live store.
Correct record ages: She no longer reports something written minutes ago as being from hundreds of days back.
Long conversations hold up: Conversations that outgrow the model's context window trim the oldest material in stages instead of failing the turn. Resolved items stop resurfacing, and starting a new conversation clears the previous one's working memory.

Web Search

Freshness ranking: Results carry a publication date signal, so recent sources rank above stale ones.
Fewer wrong triggers: Thinking-out-loud phrases like "that's what I'm trying to figure out" no longer read as a search request, and image turns no longer trigger a search.

Interface

Accessibility: WCAG 2.1 AA pass, 12 fixes across contrast, focus, labelling, and keyboard navigation, with an automated check that runs on every change.
Review is visible: A breathing dot appears while Ember reviews a draft, so a pause reads as work rather than a hang.
Correct source badges: Vault answers no longer get labelled as though they came from the web.
Smaller fixes: Assigning a conversation to a project retries once instead of silently dropping, and the service status panel closes when you click away.

Installer

Linux support: Build configuration, CI, and platform-gated install paths, with startup task, Docker, reboot, and self-update handling hardened for Linux.
Update checks compare numbers: Version comparison was string-based, which breaks once numbers reach two digits. Exactly the jump this release makes.
These notes render again: The release notes file was not being bundled into the build, so this panel came up empty.
Current model lineup: A fresh install now offers the qwen3 family rather than the older curated set.
Security and logs: Values rendered into the installer window are inserted as text, not markup. Duplicate install log lines are fixed, and a button whose background work fails no longer leaves an unhandled error.

Known Issues

Tone on emotional topics: At qwen3:8b scale, register still drifts below target on emotional queries. The coaching filter reduces it but does not eliminate it. A larger model handles it better.
No confidence signal on recall: Vault-retrieved content is presented with uniform confidence regardless of how well it matched or how old it is.
